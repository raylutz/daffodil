## Decided and done since the 2026-10-06 handoff
- 0.7.0 released, with: KeyedIndex removed (a KeyedList's hd is a plain dict, and rows share the Daf's hd);
  default_record() follows the Daf's columns, has astype=KeyedList, and keeps a template (15.5 to 1.25 µs);
  append() and from_lod() fast=True; append(list) without a dict round trip; selections no longer copy the
  row list (clone_empty fix); the profiling mode, daf_profile.py, with stages and combine; X | None annotations.
- fast=True rules, as Ray settled them: a KeyedList must share daf.hd, then nothing else is checked; a dict or
  list is checked fully on the first row of an empty Daf and only for length after; ValueError messages say
  which row, what differs, and how to fix it. Without fast, every row is checked and copied.
- Deploys by branch: main runs nothing. CI runs on pull requests, when full_deploy calls it, and by hand.
  Docs alone deploy by `git push origin origin/main:refs/heads/docs_deploy`, only when Ray asks.
  Run notes/scripts/check_before_push.sh before any push to main.
- Docs: a Guide of 9 pages built from the old README, with tested examples (pytest --doctest-glob='*.md'
  docsite/guide, using conftest.py); a short README with the logo and the new diagram; a cheatsheet,
  docsite/cheatsheet.md, with a skill header, tables made by Daf.to_md(), every snippet tested by
  tests/test_cheatsheet.py; an indexing reference in the cheatsheet and the Guide. Source for both:
