# A bool converted to str is now '1' or '0'

Ray set a standing rule on 2026-10-26, Q299. In daffodil a boolean is the int 0 or 1, never True or False.
Converted to str, it is '1' or '0'.

- Before be7f1d2, a Python True in a column with dtype str became the int 1 under `apply_dtypes(from_str=False)`.
  Now it becomes the text '1'.
- Your call at utilities/archives.py:1705, `apply_dtypes(from_str=False)`, is the one place this can reach.
  It changes only a str column that holds a Python bool.
- `update_with_history()` is not affected for you, since your flags are 0 and 1 already.

The standard is on a new Guide page, docsite/guide/booleans.md, and in the cheatsheet rules.
Rows you build should hold 0 and 1. `normalize_val()` in daf_utils.py turns bools into 0 and 1 at any depth.
