# Addition to 2026-10-30_2240_agent_settings_and_safeguards.md: open data comes first

Ray added this on 2026-10-30.

- Git holds code and settings only, not the election data.
  Safeguard 2 means the settings changes go to git. Nothing else does.
- Operation relies on AI only in the trained ML stages for image recognition.
- The primary safeguard is open data. Anyone can check the results from the data,
  without knowing how the code works.
- The jurisdiction performs the official count. AuditEngine only detects discrepancies.
  Large enough discrepancies lead to a hand count of the paper. No result is overturned on an audit platform's word.

So the four safeguards support open data. They do not replace it.
